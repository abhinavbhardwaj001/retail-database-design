# Virtual Retail Database – Data Modeling and Architecture (Week 1)

Data model for "NovaMart", a fictional multi-warehouse online retailer (18 tables, 3NF, PostgreSQL).

| File | Purpose |
|---|---|
| `schema.sql` | Complete DDL: tables, primary/foreign keys, constraints |
| `indexes.sql` | Indexing strategy |
| `queries.sql` | 8 decision-support queries (sales, margin, stock, customers, suppliers) |
| `diagrams/` | Conceptual ERD, logical ERDs, architecture diagram (PNG) |

Run order: `schema.sql` -> `indexes.sql` -> `queries.sql`. Full explanation is in the Word report.
